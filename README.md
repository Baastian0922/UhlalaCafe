# ☕ Uhlala Café — Landing Page Premium

Bienvenido al repositorio de la landing page de **Uhlala Café**, una experiencia digital premium diseñada para reflejar la esencia de una cafetería de especialidad exclusiva, ubicada en la altura de Macul Alto, Santiago de Chile.

El sitio web está optimizado para transmitir la calidez de un negocio **atendido por su propia dueña**, donde cada preparación se realiza de forma casera y con amor, en un entorno rodeado de flores y mesas blancas con una hermosa vista a la ciudad y atardeceres mágicos.

---

## ✨ Características Principales

*   **Diseño Premium y Sofisticado:** Paleta de colores basada en oro rosa (rose-gold) y platino, con efectos de glassmorphism y micro-animaciones dinámicas.
*   **Contenido Personalizado:**
    *   **Terraza y Atardeceres:** Secciones dedicadas a la atmósfera del local con vistas a la ciudad.
    *   **Flores y Mesas Blancas:** Diseño visual coherente que refleja el entorno real del café.
    *   **Hospitalidad:** Relatos e imágenes enfocadas en la atención cercana y casera de su dueña.
    *   **Amenidades:** Espacio con música de jazz ambiental y acceso a Wifi liberado.
*   **Widget Interactivo "Descubrir mi Taza":** Un test interactivo paso a paso desarrollado en JavaScript puro que recomienda el café y método ideal según las preferencias del usuario.
*   **Carta Dinámica:** Menú interactivo por pestañas con transiciones fluidas para explorar las opciones de Cafés de Autor, Pastelería de Alta Gama y Brunch Signature.
*   **Ubicación e Información en Tiempo Real:** Enlace directo a Google Maps y acceso directo a WhatsApp para consultar aforo, con horarios de atención actualizados (Lunes a Sábado de 10:00 AM a 9:00 PM).
*   **100% Responsivo:** Adaptabilidad móvil de primer nivel, incluyendo una barra de navegación inferior flotante exclusiva para dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas

*   **Estructura:** HTML5 Semántico y accesible.
*   **Estilos:** CSS3 nativo (sin frameworks como Tailwind, garantizando máxima personalización y tiempos de carga óptimos).
*   **Lógica:** Vanilla JavaScript (cero dependencias externas, uso de `IntersectionObserver` para scroll-spy y transiciones dinámicas).
*   **Tipografía:** Google Fonts (Playfair Display para títulos serif, Inter para textos sans-serif).
*   **Iconografía:** FontAwesome v6.

## 🚀 Cómo Ejecutar el Proyecto Localmente

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/Baastian0922/UhlalaCafe.git
   ```
2. **Navega a la carpeta del proyecto:**
   ```bash
   cd UhlalaCafe
   ```
3. **Abre el archivo principal:**
   Simplemente haz doble clic en `index.html` o usa una extensión de servidor local como *Live Server* en VS Code para experimentar las transiciones en tiempo real.
